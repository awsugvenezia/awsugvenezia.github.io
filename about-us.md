## AWS User Groups

[AWS User Groups](https://builder.aws.com/community/user-groups) are community-led groups where builders meet to discuss the latest in AWS Cloud, learn new skills from like-minded peers, and network with builders in their local AWS community.

There are more than 590 AWS User Groups in 100 countries around the world, with meetups held in person or virtually.

## AWS User Group Venezia

[AWS User Group Venezia](https://www.meetup.com/aws-user-group-venezia/) is the group for all cloud and AWS enthusiasts: it has 781 members and 18 events.

## How we organize our meetups

The group is open to all levels, from newbies to advanced: we give space and reasons for interest to everyone. We organize events on various topics related to the AWS world: you can join in person, when possible, or follow our live streaming, then saved on [YouTube](https://www.youtube.com/@{{ site.youtube_channel }}).

## Other initiatives

Besides the meetups, we organize competitions based on AWS game-based learning: [AWS Cloud Quest](https://aws.amazon.com/training/digital/aws-cloud-quest/), the 3D role-playing game that helps you build hands-on AWS skills, [AWS Jam](https://aws.amazon.com/training/digital/aws-jam/), the team competition to test yourself with real-world scenarios, and [AWS Card Clash](https://aws.amazon.com/training/digital/aws-card-clash/), the card game to learn AWS architectures by completing them with the right services.

## AWS User Groups

Gli [AWS User Group](https://builder.aws.com/community/user-groups) sono gruppi guidati dalla community, in cui i builder si incontrano per discutere le novità del cloud AWS, imparare nuove competenze da altri appassionati e fare rete con i builder della propria community AWS locale.

Esistono più di 590 AWS User Group in 100 paesi nel mondo, con meetup in presenza o virtuali.

## AWS User Group Venezia

[AWS User Group Venezia](https://www.meetup.com/aws-user-group-venezia/) è il gruppo per tutti gli appassionati di cloud ed AWS: conta 781 membri e 18 eventi.

## Come organizziamo i meetup

Il gruppo è aperto a tutti i livelli, sia newbie che advanced: diamo spazio e motivo d'interesse a tutti. Organizziamo eventi su vari argomenti relativi al mondo di AWS: puoi partecipare di persona, se possibile, o seguire uno dei nostri streaming in diretta, poi salvati su [YouTube](https://www.youtube.com/@{{ site.youtube_channel }}).

## Altre iniziative

Oltre ai meetup, organizziamo competizioni basate sui giochi di apprendimento di AWS: [AWS Cloud Quest](https://aws.amazon.com/training/digital/aws-cloud-quest/), il gioco di ruolo 3D che aiuta a sviluppare competenze pratiche per il cloud AWS, [AWS Jam](https://aws.amazon.com/training/digital/aws-jam/), la competizione per team che si vogliono mettere alla prova con scenari reali, e [AWS Card Clash](https://aws.amazon.com/training/digital/aws-card-clash/), il gioco di carte per imparare le architetture AWS completandole con i servizi giusti.
